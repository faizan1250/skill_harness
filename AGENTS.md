# Repository Guidelines for AI Agents

This is Saif's personal skills library (`/home/faizan/SKILLS`).

- **Branching Rule**: Never commit to `main`. Always create a branch (`fix/`, `feat/`, `chore/`, `refactor/`), commit there, push, and open a PR. The owner merges.
- **Skill Paths**: All skills live under `/home/faizan/SKILLS`. Use absolute paths (`/home/faizan/SKILLS/<skill-name>/skills.md`) or forward-slash normalized paths.
- **Commits**: When tasks are fully done and verified, stage with `git add .`, commit on the feature branch, push, and open a PR. Never push directly to `main`.
